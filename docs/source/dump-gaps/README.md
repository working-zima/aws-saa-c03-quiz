# 880문항 덤프 해설에서 추출한 보충 개념 (SAA-C03)

> 원본: `docs/source/pdf/SAA-C03_해설집.pdf` — 595페이지, 880문항, 덤프 V29.35.
> `concepts-raw.md`(개념 원문)와 `exam-gaps.md`(163문항 덤프)에 **없는데 이 해설에서
> 정답 근거로 쓰인 것**만 추린다. 앞의 두 곳에 이미 있는 내용은 여기에 다시 적지 않는다.
> 근거는 ADR-021.
>
> **문항은 가져오지 않는다.** 개념만 추린다. 복수정답이 78문항이라 ADR-005의 4지선다
> 단일정답과 어긋나고, 문제 전문을 저장소에 넣으면 ADR-009의 전사 금지와 부딪힌다.
>
> **추출 방법** — 이 계열 PDF의 라틴 폰트는 ToUnicode 매핑이 깨져 있어 PyPDF2로 뽑으면
> 영문에 붙은 숫자가 치환된다(`EC2`→`EC~`, `S3`→`S\x87`). pypdfium2는 정상 추출한다.
> `docs/source/exam-gaps.md` 헤더에 기록된 실측이고 이 PDF에서도 같다.
>
> ```
> python3.13 -m venv .venv && .venv/bin/pip install pypdfium2
> .venv/bin/python scripts/extract-dump.py
> ```
>
> 저장소 기본 `python3`는 3.7이라 pypdfium2가 깔리지 않는다. Python 3.13 이상을 쓴다.
>
> **슬라이스 18개** — 595페이지를 한 번에 읽으면 컨텍스트가 남지 않으므로
> `scripts/extract-dump.py`가 50문항 단위로 잘라 `docs/source/dump-slices/`에 쓴다.
> `Q001-Q050.md` … `Q801-Q850.md`, `Q851-Q880.md`(마지막만 30문항).
> **슬라이스는 덤프 전문이라 커밋하지 않는다** — `concepts-raw.md`와 같은 취급이다(.gitignore).
> 이 디렉토리의 결과 파일과 `_index.md`만 커밋한다.
>
> **근거 표기** — `[Q번호 p쪽]`. 문항 번호는 덤프 전체에서 유일하므로 섹션명이 필요 없다.
> 쪽번호는 PDF에 인쇄된 값이고, 슬라이스의 `<!-- Q123 p456 -->` 주석에서 읽는다.
>
> **중복 방지** — 새로 만든 개념은 `_index.md`에 한 줄씩 append한다. step이 18개로 나뉘어
> 있어 앞 step이 무엇을 만들었는지 그 파일로만 알 수 있다. 앱에 이미 있는 개념 182개는
> `scripts/concept-index.py`가 만드는 `docs/source/concept-index.md`로 확인한다.
>
> **덤프를 그대로 따르지 않은 항목** — 각 슬라이스 결과 파일 끝의 "원본 수정 이력" 절에
> 적는다. `exam-gaps.md`가 문서 하나라 맨 끝에 모아 둔 것과 달리, 여기는 파일이 18개로
> 나뉘므로 해당 파일 안에 둔다. 덤프 해설이 실제 AWS 동작과 어긋나면 정확한 쪽으로 고쳐
> 싣거나 싣지 않고, 어느 쪽이든 덤프 원문을 함께 남긴다(ADR-008의 예외를 승계한 ADR-021).
>
> **해설집이 스스로 밝힌 불확실성** — 문서 2쪽에 이렇게 적혀 있다. "원본에 해설이 없던
> 21개 문제는 새로 작성했고 `[AI 작성 해설]`로 표시했다. 그중 6개 문제는 원본에 기록된
> 정답이 AWS 기준과 어긋난다." 슬라이스에서 `[AI 작성 해설]` 표시가 붙은 해설은
> 근거로 쓰기 전에 한 번 더 의심한다.
>
> **슬라이스에 남아 있는 잡음** — 인용할 때 걸러낼 것:
> - 해설 끝의 참고 자료 목록은 잘라냈다(`참고 자료:` · `참고 문헌:` · `참고 발췌문:` ·
>   `AWS 참조:` · `참고:` 이후 전부). AWS 문서 링크 목록이라 정답 근거가 아니다.
> - 그 목록의 다른 표기인 `참조:`로 시작하는 줄 29개와 `자료:` 1개는 남아 있다.
>   같은 성격의 링크 목록이므로 개념으로 삼지 마라.
> - `참고:` 이후를 자르면서 선택지별 분석이 함께 잘린 문항이 있다(가장 큰 것이 Q507,
>   약 1000자). 정답과 본 해설은 남으므로 정답 근거는 보존된다.

## 결과 파일

step마다 슬라이스 하나를 읽고 결과를 이 디렉토리에 쓴다.
파일명은 슬라이스와 같다: `Q001-Q050.md` … `Q851-Q880.md`.

항목 형식은 `exam-gaps.md`를 그대로 따른다.

```markdown
## {topicId}

### `{conceptId}` — 개념 이름

**한 줄**: 한 줄 요약.

본문 문단. 사실만 가져오고 문장은 직접 쓴다. 덤프 문장을 그대로 옮기지 마라(ADR-009).

> [Q123 p456] "덤프 원문 인용"
```

`{topicId}`는 `src/data/topics.json`의 주제 id다. 어느 주제에도 들어맞지 않는 개념은
주제를 새로 만들지 말고 그 사실을 항목에 적어 둔다 — **주제 배치는 phase 26이 끝냈다.**
정한 골격은 `topic-plan.md`에, 그 결과로 들어간 실제 데이터는 `src/data/topics.json`에 있다.
