# Route 53 물음형 제목·예시의 브라우저 실측 (2026-09-27)

worktree(`../aws-saa-c03-quiz-p44`)에서 빌드 후 `vite preview`를 띄우고 Claude in Chrome으로 고정 폭 iframe(320·390·1280)에
`/#/topic/route53`을 열어 쟀다. **시나리오 버튼을 누르는 호출과 재는 호출을 나눴다.** 같은 동기 호출 안에서 누르고 바로 재면 전환이
반영되지 않은 값이 나오기 때문이다. phase 43 `measurements.md`의 390px 캡션 줄 수(「모두 2줄」)는 그렇게 잰 값이 섞여 있었다.
이번에 다시 재니 390px에서 `단순` 캡션은 1줄이었다. "2줄 이하"라는 판정은 그대로다.
**이 파일에 없는 숫자를 지어내지 마라.**

## 공통

| 항목 | 320px | 390px | 1280px |
|---|---|---|---|
| 문서 가로 넘침 | 없음 (scrollWidth 320) | 없음 (390) | 없음 (1280) |
| 도식 SVG 표시 폭 | 320px | 380px | 380px |
| 물음 제목 줄 수 | 셋 모두 1줄 | 셋 모두 1줄 | 셋 모두 1줄 |
| 시나리오 버튼 최소 높이 | 44px | 44px | 44px |
| console error(로드 뒤) | 0 | 0 | 0 |

물음 제목은 세 도식 모두 `figure`의 첫 자식 `<p>`이고, 버튼 줄보다 위에 있다.

## 도식별

figure 높이는 `전체` 상태에서 320 / 390 / 1280px로 쟀다.

| 도식 | `viewBox` | figure 높이 | SVG 글자 오른쪽 끝 최댓값(`getBBox`) |
|---|---|---|---|
| 상태 검사와 Route 53 응답 | `0 0 280 244` | 569 / 605 / 589 | 268 (`www.example.com의 주소는?`) |
| 별칭 레코드 | `0 0 280 256` | 619 / 621 / 605 | 208(전체) · 219(인스턴스 교체) · 240(공용 IP에 직접) |
| 하이브리드 DNS 방향 | `0 0 280 352` (phase 43의 340에서 늘어남) | 728 / 804 / 736 | 244 · 253(규칙 공유) |

모두 viewBox 폭 280 안이다.

## 캡션 줄 수

`전체`와 모든 시나리오에서 320px은 모두 2줄이다. 390px은 2줄이고, 상태 도식 `단순`만 1줄이다. 1280px은 모두 1줄이다.

## 눈으로 확인한 것 (390px)

- 상태 도식 `전체`: 물음 → 버튼 → 사용자, 그 오른쪽에 `www.example.com의 주소는?` → Route 53 → `리전 A의 ALB`·`리전 B의 ALB` 순서로 보인다.
- 별칭 도식 `전체`: 맨 위 노드가 `www.example.com`이다. `공용 IP에 직접`에서는 옆 통로 화살표가 EC2에 닿고, 그 아래 대상 그룹 안에
  `공용 IP 52.123.25.11`이 보인다.
- 하이브리드 DNS `전체`: 온프레미스 박스 아래에 `db.corp.local`, 프라이빗 호스팅 영역 아래에 `app.internal.aws`가 처음부터 보인다.
  `db.corp.local`은 온프레미스 박스 바깥 아래, 두 노드 사이보다 조금 왼쪽(x 120)에 있다.
