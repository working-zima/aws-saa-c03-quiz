phase 40·41과 같은 방법이다. worktree(`../aws-saa-c03-quiz-p42`)에서 빌드 후 `vite preview`를 띄우고 Claude in Chrome으로

## 캡션 줄 수

시나리오를 하나씩 눌러 `figcaption` 글자의 줄 수를 셌다. **모든 캡션이 320px·390px에서 2줄 이하, 1280px에서 1줄**이다.
캡션은 41~47자다.

## 라벨의 실제 폭

오른쪽 열 곁말의 실제 `getBBox()` 오른쪽 끝은 `소스 = / ALB 보안 그룹` 254.1, `WAF` 249, `ALB에 붙음` 247.6이다.
viewBox 폭 280 안에 든다.

## 눈으로 확인한 것 (390px, `요청 흐름`)

인터넷 → 퍼블릭 서브넷 NACL → ALB 보안 그룹 경계 안 ALB → 프라이빗 서브넷 NACL → EC2 보안 그룹 경계 안 EC2로 화살표가
한 줄로 내려간다. WAF는 퍼블릭 서브넷 박스 밖 오른쪽에서 ALB와 화살표 없는 가는 선으로만 이어지고 아래에 `ALB에 붙음`이
붙는다. `소스 = / ALB 보안 그룹`은 EC2 보안 그룹 옆 오른쪽 열에 두 줄로 놓인다. 선이 노드 글자를 가리지 않는다.
